# RTK - Rust Token Killer

Always prefix shell commands with `rtk`.

Prefer `rtk <command>` or native commands such as `rtk read`, `rtk grep`, `rtk find`, `rtk git status`, `rtk npm run build`, and `rtk test <command>`.

Use `rtk proxy <command>` only when exact raw output is required.
