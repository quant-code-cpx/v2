摘要

问题

频率、修订与量纲比字段名更关键

基金净值、份额、季度组合、宏观指标和机构调研来自不同来源。字段可见不代表能表达旧系统的公告日、复权、季度范围或每日增量。

决策

宏观优先做能力级映射

先为验证通过的宏观能力设计 adapter DTO 和质量规则；基金能力保留 Tushare 参考契约，直到历史、单位和来源稳定性全部通过。

最大风险

详细机构调研的成本与稳定性

最近日期无明细时抛出 TypeError；月度窗口 71 秒、处理 54/176 项后同样失败。它不能作为日终同步的基础。

本轮没有生产变更未创建表、迁移、接口、任务或 AKShare adapter。所有调用仅发生在一次性只读 Docker 探针中，未挂载项目目录或数据库。

旧 Tushare 基线

能力范围来自 0002 数据总纲；旧 Prisma 模型与同步服务只用于比对数据契约和频率，不复用其代码。旧系统基金净值按基金代码周批量、份额与复权因子按交易日、组合按月、宏观按其发布频率、机构调研按日期范围获取。

能力级准入结论

条件候选：已验证核心结构，仍需补齐字段/窗口；部分候选：只能表达子集，需 ADR 或回退；暂不准入：稳定性、历史或语义已经阻断当前同步。

Capability结论映射与缺口实现前退出条件
fund.nav部分候选单位/累计净值与日期可得；缺公告日、累计分红、净资产、总净资产与显式复权净值。明确基金全集与并发/限速；补齐字段来源或将其移出 canonical 契约。
fund.share暂不准入沪市历史候选断连，深市快照解析失败；只见 ETF 语义，尚未证明旧范围。沪深交易日连续成功，确认份额单位、历史日范围、代码全集与幂等键。
fund.portfolio条件候选股票持仓、比例、万股/万元和季度可得；缺公告日、浮通股占比，季度文本需解析。对账报告期/公告期与单位；定义同基金同证券多季度的稳定键及披露修订策略。
fund.adjustment_factor暂不准入候选行情不可读，且复权价格不等价于可审计的因子。找到显式因子来源；若改为价格派生，先以 ADR 决定基准、精度和事件处理。
macro.cpi条件候选13 字段、月频和百分比口径高度同构。锁定月份解析、发布日期与修订检测；同月与 Tushare 逐字段对账。
macro.ppi部分候选只有总指数四列，旧模型含 31 项分项。寻找分项来源；否则先以 ADR 缩小 canonical 数据集，再实现 adapter。
macro.gdp条件候选旧 9 项可映射，单位同为亿元；累计季度不是单季值。定义 quarter 与累计范围的编码及修订覆盖策略。
rates.shibor条件候选2015 年后九期限同表可得；隔夜单期限可追至 2006 年。确认九期限完整历史回补、非交易日缺失和百分比精度后再准入。
research.institutional_survey仅汇总候选统计接口缺逐机构与机构类型；详细接口运行不稳。先决定是否只保留汇总；需要明细则找到稳定替代来源或直接路由 Tushare。

事实

现有 port 已足够承载能力路由

当前服务已有 DataSourcePort 与 SourceRegistry。本轮不改变其接口，不把任何 AKShare SDK 调用写入应用、任务、质量或持久化代码。

决策

优先级按能力执行

AKShare 仍为默认优先 provider；但标为暂不准入的能力，路由必须直接选择可用 provider，不能让业务任务直接重试第三方 SDK。

待决

分项与修订进入 canonical 前必须决策

PPI 分项、基金复权因子、机构调研明细和宏观发布修订会影响 schema。未决定前不创建业务表或迁移。

禁止绕过 adapter供应商 SDK、HTTP 地址和原始字段只能位于独立 adapter；adapter 返回 provider DTO，不直接写 canonical 数据库。这是 ADR-0004 与服务架构测试的边界。

下一步与验收

  1. 发布窗口连续观察：CPI/PPI/GDP 在各自发布月，Shibor 在连续交易日，基金净值在收盘更新后，记录最新观测期、修订和成功率。
  2. 同日对账：对候选能力与旧 Tushare 样本逐字段比对。基金组合先完成万股/万元换算、季度和公告期解析；宏观先完成统计期编码。
  3. 只实现通过项：先定义 provider DTO、mapper 与质量测试；基金份额、复权因子、详细调研仍保持 Tushare 或其他 provider 路由，不建同步任务。

主要风险

基金与调研来源多次在数据量或响应阶段失败。必须设能力级超时、失败分类和回退，不得因宏观接口稳定而推广至整个 AKShare。

待决问题

旧 PPI 31 字段是否继续保留；ETF 复权因子是否必须保留为显式序列；机构调研是否接受汇总降级。它们需要字段对账后再写 ADR。

外部证据

AKShare 公募基金文档说明净值、ETF 份额、组合持仓的参数和单位；宏观数据文档说明 CPI/PPI/GDP 的频率和口径；利率数据文档说明 Shibor 单期限利率与 BP 变动。
