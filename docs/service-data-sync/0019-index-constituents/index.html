Proposed 方案编号 0019 · service-data-sync / 指数域 · 2026-07-28

指数目录、成分与权重的 point-in-time 数据接入方案

建议以“少量高价值宽基指数 + 官方生效事件”为 P0，先建立可审计的指数身份、 成分生效区间与披露可见时间；当前成分/收盘权重仅作为观测快照，绝不倒推历史。 中证与国证保持独立来源策略，统一到 Provider-neutral canonical dataset。

推荐选择
P0 条件接入；拒绝“全量目录一次性接入”

先覆盖中证 300/500/1000、上证 50、深证成指、创业板指等白名单； P1 再扩展历史快照、收盘权重与更多指数。

关键理由
研究价值高，但时间语义比抓取本身更重要

选股池、基准归因、ETF 跟踪与 PIT 回测均依赖准确的公告时间、生效时间、 修订版本和证券身份。

首要风险
把“今天看到的成分”伪装成历史有效成分

AKShare 当前快照不证明历史完整；固定版本与在线文档也存在语义漂移， 必须经连续探测、公告对账和回放门禁后才能发布。

1. 结论与优先级

本文状态为 Proposed，仅提出数据接入、模型与消费需求； 不代表已批准 Provider、已完成生产接入或已接受跨服务契约。

建议 接入指数数据，但把“官方有效成分”和“抓取时观察到的当前成分”拆成两种不可互换的语义。 P0 只有得到明确生效证据的记录可进入 PIT 数据集；观测快照可以先用于当日展示与差异侦测， 但必须标记为 OBSERVED_CURRENT，不得用于历史回测。
优先级 范围 建议 发布能力 进入下一阶段的条件
P0 中证 300/500/1000、上证 50、深证成指、创业板指等 6～10 条高价值 A 股宽基指数；指数身份、方法学版本、正式调样事件 建议接入 指数目录；有官方证据的有效成分；公告与生效事件；当前观测快照隔离发布 固定版本函数验证、证券身份 100% 解析、公告—生效对账、可回放恢复通过
P1 官方收盘权重、更多可投资宽基/行业指数、国证历史样本与历史调样、 中证历史档案补齐 条件接入 按日权重、完整快照、可配置 PIT 查询、修订版本 历史深度实测、权重口径确认、数据再分发范围确认、连续稳定性达标
P2 长尾主题指数、停编/代码链自动化、其他指数管理人和非股票指数目录 按需接入 扩展目录与生命周期；非股票成分仍按资产域隔离 明确消费者、资产身份与日历边界，且增量成本低于独立采购/按需查询

推荐来源路线

  • 业务来源身份：中证指数有限公司、深圳证券信息有限公司（国证指数）。
  • 采集实现：初期允许在 Adapter 内使用仓库固定 AKShare 版本。
  • 时间证据：官方调样/修订公告、方法学文件及其哈希。
  • 不得把 AKShare 名称写入 canonical 字段或对外响应。

明确不建议

  • 不从当前成分文件倒推过去任意日期的成分。
  • 不把收盘权重当成下次调样的目标权重。
  • 不按代码或名称跨管理人静默合并指数。
  • 不在 Adapter 外访问 SDK、URL 或保留供应商字段。

2.2 领域边界

  • 本专题负责指数目录、指数生命周期、方法学版本、成分/权重快照、调样与修订事件。
  • 股票身份与代码复用由既有 0014 股票主数据方案 及其后续统一模型负责；本域只保存不可变的身份引用和上游原值。
  • 交易日历、来源批次、原始载荷、质量结果、隔离记录、发布版本和 checkpoint 为跨专题共享能力，留给后续统一 canonical data model 方案定义。
  • 指数行情、ETF NAV、衍生品合约和公司财务不是本专题表；可以通过指数身份关联， 不得混表。
  • 非股票指数可以进入目录，但其成分必须等对应资产身份域就绪后再发布，避免把债券、 期货或基金代码误解为股票代码。
范围假设 P0 消费者优先需要 A 股宽基指数，白名单暂按 6～10 条估算。最终白名单由量化研究负责人在 P0 开始前确认；若未确认，技术兜底为仅启用中证 300/500/1000、上证 50、深证成指、 创业板指，其他指数保持禁用。

3. 事实、推断、建议与未决

分类 陈述 证据/理由 对方案的影响
事实 仓库固定 akshare==1.18.78；现有 0005 探测中，中证权重接口对 000300、000016、000905、899050 返回一个 2026-06-30 快照， 399006 失败。 0005 B03 调研 的短样本证据；本次仅离线检查固定镜像中的函数签名与实现，未重复联网探测。 不能把单次成功视作稳定接入，也不能假设中证接口覆盖国证代码。

事实 官方方法学的调样频率不是全局常量：中证指数可按半年、季度或临时规则调整； 国证公告也存在代码、名称、方法学与生效日同时变化。 中证股票指数样本调整规则、具体指数方法学及国证官方修订公告。 频率、缓冲区和权重限制必须绑定方法学版本，不可写死在共享任务中。
事实 现有代码没有指数目录、指数成分或权重的生产模型、任务与路由。 CodeGraph 对相关 capability、Adapter、模型与客户端的检索；最近的可复用链路是 板块成分同步与股票身份解析。 需要新建指数域，不能复用板块表伪装指数。
建议 按管理人和数据集固定来源策略；数据集之间可以组合，但一条记录不得静默混用来源。 中证与国证覆盖、字段、历史深度和调样文件语义不同。 任务、批次、版本和查询响应均携带来源策略与方法学版本。
假设 P0 以公开官方文件支撑内部研究使用；是否允许长期存储、对外再分发原始权重或完整成分， 尚未取得逐项确认。 官网公开可访问不自动等于允许任意再分发。 不阻断方案与影子同步，但阻断对应字段的生产外发，详见 G2。
未决 中证历史成分/权重的公开可得深度、公告文件稳定 URL 与修订保留策略。 当前 AKShare 中证接口只明确“最新成分/权重”。 P1 回补可能需要官方历史档案或授权数据，不得用当前快照替代。

4.1 Provider Adapter 约束

  • Adapter 对内只实现 Provider-neutral capability： index.catalog.snapshot、 index.constituent.snapshot、 index.weight.snapshot、 index.adjustment.history、 index.methodology.document。
  • SDK 名、URL、工作表名、中文原始列名、坏 ZIP 特判、分页参数和请求头只能存在于 Adapter； Adapter 不写数据库。
  • 每个 capability 固定 source_policy、固定管理人、固定 adapter_version 与 schema_fingerprint； 上游异常时不得切到其他来源并沿用同一数据版本。
  • 生产启用前至少对 P0 白名单完成 5 个连续交易日短探测和一次正式调样窗口回放； “单次调通”只记为实验事实。
版本漂移处理 线上 AKShare 文档当前为 1.18.80，而仓库固定 1.18.78。设计与验收以固定镜像真实行为为准； 在线文档只作候选说明。任何依赖升级均另立变更，不在本文范围内。

5. Canonical dataset、粒度与字段字典

5.1 建议的数据集边界

dataset 标识 业务粒度 候选唯一键 时间主轴 主要消费者
index.catalog 一个管理人下的一条指数身份版本 (administrator_code, index_code, valid_from, known_from) 身份有效区间 + 系统知悉区间 指数检索、ETF 跟踪标的、所有下游外键
index.methodology.version 一条指数的一版方法学 (index_id, methodology_hash, effective_from) 发布、有效、抓取、修订时间 规则解释、权重口径、调样频率审计
index.constituent.observed_snapshot 一次观察到的完整快照中的一只证券 (snapshot_id, security_id) 来源日期 + 观察时间；无证据时无有效区间 最新展示、差异侦测；默认禁止历史回测
index.constituent.effective 一条指数在一个有效区间内的一只证券 (index_id, security_id, effective_from, revision_no) 生效区间 + 来源可见时间 + 修订知悉区间 PIT 样本池、事件研究、基准归因
index.weight.close 一条指数在一个来源日期的一只证券的官方收盘权重 (index_id, security_id, weight_date, weight_type, revision_no) 权重日期 + 来源可见时间 权重暴露、集中度、跟踪对比
index.adjustment.event 一份公告/修订中的一个指数事件及其证券动作 (index_id, upstream_notice_id, revision_no, item_seq) 公告、可见、生效、修订时间 调样日历、PIT 重建、代码/停编生命周期
语义隔离 observed_snapshot 与 effective 是不同数据集： 前者回答“系统在何时看见官网当前列表”，后者回答“官方证据表明哪段交易日有效”。 即使两者内容相同，也不能通过改字段标志在原位互换。

5.2 候选实体身份

  • 指数全局身份不得只用六位代码；候选业务键为 administrator_code + index_code + valid interval。 同名不同管理人保持不同 index_id。
  • 代码、简称、全称都可随时间变化。代码变更建立 identifier 版本链，不创建无关的新指数； 是否延续同一指数以官方公告为证据。
  • 成分证券通过交易所、证券代码、事实日期与系统知悉时间调用股票身份解析； 不以证券名称匹配，无法唯一解析即隔离整份正式快照。
  • 管理人、指数、证券和方法学均保存上游原始标识，便于审计；原始标识不作为跨服务公共 ID。

quality_status text — 不可为空 候选状态：RELEASED、WARN、QUARANTINED。

6. 时态、调样与 point-in-time 重建

指数数据至少同时存在“来源何时公开”“规则何时生效”“系统何时知悉”三条时间轴。 任一轴缺失都不能用当前记录填补。

方法学评审 内部计算可能已完成，但对消费者不可见，不进入数据。
公告发布 announced_at / source_visible_at，可用于预告。
系统采集 system_known_from，记录真实运行态知悉时间。
调整生效 effective_from，通常在指定收盘后或下一交易日。
后续修订 新 revision_no，关闭旧知悉区间但保留旧事实。

6.1 两种 as-of 语义

查询模式 过滤规则 用途 限制
PUBLIC_PIT source_visible_at ≤ as_of 且 effective_from ≤ trade_date < effective_to 历史回测中模拟当时公开信息；允许后来回补旧公告。 必须保留发布时间精度和保守推导规则，禁止回填假精确时间。
OPERATIONAL_REPLAY 在前述条件上增加 system_known_from ≤ as_of < system_known_to 复现平台在某一时刻实际对外服务的版本。 历史回补前的运行时刻不会看到后来补录的信息。

6.2 成分与权重重建规则

  1. 先按指数身份版本解析查询日期，处理代码变更、停编和同代码复用，再选择成分。
  2. 调样公告可以在生效前对消费者可见，但新成分只能从 effective_from 起进入指数；公告日收益不得归因给尚未生效成分。
  3. 只有明确的官方公告、历史调样文件或带生效日期的权威快照，才可构造 index.constituent.effective。
  4. 当前快照之间的差异只能生成“候选变更”，不能自动把上次观察日至本次观察日写成真实有效区间。
  5. 一份不健康或不完整的新快照不能关闭旧有效区间；先隔离，待完整快照或正式事件证据到达。
  6. 收盘权重按 weight_date 使用。若查询日没有同日权重，默认返回缺失， 不插值、不把调样目标权重向后填充；消费者可显式请求“最近已知官方收盘权重”， 响应必须携带原权重日期。
  7. 若公告只有日期、没有时间，保存 DATE_ONLY，PIT 可用时间保守设为官方市场的 下一交易日开盘；若能验证当日收盘前已公开，才使用更早时刻。
官方示例 中证 300 方法学说明半年定期审核通常在 5 月下旬、11 月下旬，调整通常在 6 月、12 月第二个 星期五的下一交易日实施；但其他中证指数存在季度、事件触发或跟随母指数调整。 因此该规则只属于对应方法学版本，不能成为全域默认值。国证官方公告也证明“公告日期”和 “实施日期”是两个字段，且代码与名称可能在实施日同时改变。

6.3 修订、撤回、停编与代码变化

  • 更正和补充披露追加新版本，并通过 supersedes_revision_no 指向旧版本； 旧版本仍可用于运行态重放。
  • 撤回事件保存为新修订状态，不物理删除原公告；受影响有效区间从最早受影响事件重算。
  • 停编设置指数生命周期终点，不删除历史成分、权重和方法学；终止后的查询返回明确状态。
  • 代码变化以官方连续性证据连接 identifier 版本；若公告未说明延续，则进入人工复核， 不按名称自动合并。

8.2 明确禁止的未来函数

不得进入 PIT 数据集

  • 公告后收益、调入后表现、未来收益排名等事后字段。
  • 未来已知的成分、权重、调样结果或后续更正版。
  • 使用今天的完整成分回填过去交易日。
  • 把“历史回补日期”伪装成当时公开时间。
  • 用最终修订值覆盖原版本而保留原可见时间。

不得静默混算

  • 中证与国证同名/同码记录。
  • 官方收盘权重与目标调样权重。
  • 观察快照日期与正式生效日期。
  • 股票、债券、基金、期货等不同资产成分。
  • 未确认单位的总市值与平台统一人民币金额。

8.3 可观测性与质量结果

  • 任务指标：来源请求成功率、429/5xx、延迟、载荷字节、schema fingerprint、 批次/分区耗时、重试与失败原因。
  • 数据指标：目录数量、每指数样本数、解析率、重复数、权重合计、变化率、 公告—快照差异、最大数据新鲜度。
  • 发布指标：隔离分区数、当前 data_version、回退次数、修订传播延迟、 消费者缓存命中/旧版本拒绝。

9.1 物理与保留建议（待统一模型确认）

  • 元数据、方法学与事件预计低量，不分区；快照 item 按 source_as_of_date 月分区，便于回补、归档和日期扫描。
  • 原始载荷、来源批次、质量结果、隔离记录、checkpoint、交易日历和发布指针不得在本域重复建表； 只保存共享外键。
  • canonical 与修订记录永久保留或按合规策略归档，不通过“最新化”删除； 原始载荷保留期须覆盖审计与重放需求，默认建议不少于 7 年，最终以统一模型和授权结论为准。
  • 回滚通过发布指针和修订状态完成；迁移计划必须可先双写/影子校验、再切读、最后清理旧读路径。

10. 对 service-api 的查询与权限需求

本节只提出消费者需求，不冻结 endpoint 或跨服务通信方案。 data-sync → service-api 的最终 HTTP/事件选择、DTO 和机器可读契约由后续跨服务专题评审。

既有架构约束 service-api 不得直读 data-sync 数据库，也不得访问中证、国证或 AKShare； service-web 只访问 service-api。当前 ADR 方向为 data-sync 持有数据并提供版本化内部 HTTP， 对外 service-api 新路由只能使用 POST。

10.2 DTO 与响应元数据需求

  • 请求必须严格校验管理人、指数代码、日期范围、时区、pitMode、 weightType、字段白名单、排序和页大小；未知字段拒绝。
  • 游标绑定过滤摘要、排序、dataVersion 与权限范围；版本过期返回明确冲突错误， 不静默跳到最新数据。
  • 响应至少携带 dataVersion、sourceAdministrator、 methodologyVersion、qualityStatus、 sourceVisibleAt、时间精度、权重日期/类型和 PIT 模式。
  • 公共响应不暴露内部批次 ID、对象存储键、Provider 实现、数据库 ID 或原始 URL； 通过稳定来源标识和官方披露链接提供可解释性。
  • 无权访问返回 service-api 统一的 403；参数错误 400；无匹配结果为成功空列表； 上游未发布/质量隔离映射为可重试的 503 或业务不可用码，不能退回旧数据而不声明。

10.3 内部消费非功能需求

  • 服务身份认证默认沿用内部 Bearer token；后续可演进短期凭证，不在本文定案。
  • 内部读取须有超时、有限重试、限流、熔断和审计；POST 公共请求的重试不产生写副作用。
  • service-api 只缓存带版本的读结果；data-sync 发布回退时能按版本主动失效或自然到期。
  • 如果后续选择事件模式，service-api 只能消费事件构建自己的授权读模型， 仍不得读 data-sync 数据库；事件顺序、重放和幂等由跨服务契约专题定义。

11.2 分阶段实施

P0-A：影子探测与身份基座
固定白名单；建立管理人/指数身份与方法学原文；连续 5 个交易日抓取目录、当前成分、 权重；不对外发布。
P0-B：正式事件与 PIT 成分
解析官方公告和生效时间；完成证券身份解析、差异对账、修订与回放； 只发布有明确证据的有效成分。
P0-C：受控消费
经后续跨服务契约接入 service-api；先面向内测权限开放，版本化缓存， 监控空结果、旧游标和回退。
P1：权重与历史扩展
验证国证历史范围和中证历史来源；校准权重单位/合计；回补按年份执行， 与日常任务资源隔离。
P2：长尾与生命周期自动化
按消费者价值扩展指数；自动识别停编、代码链和方法学变化； 非股票成分保持独立资产域。

11.3 可复用与必须隔离

可复用基础设施

  • Provider Adapter、原始载荷、来源批次、schema fingerprint。
  • 股票身份解析、交易日历、质量结果、隔离与发布指针。
  • 任务锁、checkpoint、审计、回放与内部服务认证。
  • 既有板块快照“坏快照不关闭旧区间”的安全原则。

必须隔离的语义

  • 指数正式有效成分 vs 板块观察到的当前成员。
  • 中证 vs 国证的管理人、目录、历史和方法学。
  • 权重快照 vs 成分有效区间 vs 调样目标。
  • 股票指数 vs 债券/基金/衍生品指数成分身份。
