1. 总结论

P0 先建共享证据与发布边界

统一身份、日历、来源、raw、双时态、质量、隔离、checkpoint、不可变 publication 和 fencing；任何专题不得复制一套。

P0 按 capability 分区接入

每个交易所、来源、字段族独立过门禁。单一 Provider 失败只关闭对应 capability，不阻断其他已达标域。

P1 HTTP-only v1 对外供数

data-sync 通过内部 POST catalog/query 提供不可变版本；service-api 映射领域 POST API，不直连数据库、对象存储或 Provider。

推荐裁决：个人使用场景固定 AKShare 为采集入口，仅内部研究、禁止再分发；真实上游仍逐 capability 记录。先落共享模型与 P0 小规模 shadow，schema、连续探针和 PIT 证据达标后逐 capability 发布；事件总线、实时 IOPV、供应商估算资金流和事后表现不进入 v1。

4. 可复用基础设施与必须隔离的数据域

共享 证据、治理与运行支撑
  • 跨域根身份、版本化标识与类型化关系
  • 场所、交易日历、产品/通道 session
  • source capability、raw object、source batch
  • methodology、lineage、quality、quarantine
  • checkpoint、lease/fencing、release/publication
  • source document 不可变版本与权限外壳
强类型 禁止万能 JSON/EAV
  • 八域事实使用 typed revision/snapshot/item 表
  • Provider 字段只存在于 Adapter/raw/normalization 血缘
  • 集合型数据都有完整 snapshot/release 头
  • reported、observed、derived 分 dataset/methodology
  • NULL、零、无记录、合法空集分别表达
隔离 不可静默合表
  • 股票、ETF、衍生品日行情
  • 指数观察快照与正式有效成员
  • 两融市场/证券/系统风险
  • 互联互通流量/活跃榜/持股
  • 公司事件与交易事件
  • 真实衍生品合约与连续序列
身份裁决：A 股库内大事实表继续使用现有 security_id BIGINT，跨服务使用稳定 UUID；ETF 拆法律基金、份额类别和 listing；指数是非交易实体；期货/期权使用 product → real contract，continuous 是独立 derived entity。不得把港股或衍生品塞入当前 A 股代码解析器。

7. 数据质量、时序防未来函数与运行恢复

三层 PIT
  • MARKET_PIT：业务有效 + publicUsableAt
  • KNOWLEDGE_PIT：再限定 canonical knownFrom/To
  • OPERATIONAL_REPLAY：再限定 publication 激活区间
时间不可替代
  • 报告期、交易日、估值日、持股日使用专名
  • sourcePublished 只保存有证据的精度
  • observedAt 回补不回拨
  • 日期-only 用保守可见规则与 basis
质量与空值
  • outcome、coverage、disposition、maturity 分维度
  • quarantine 永不 publication
  • 真实 0 与 NULL/无记录/空 snapshot 分离
  • 字段级 null reason 与分区 gap reason 分离

统一写入与恢复顺序

  1. Adapter 获取；raw object 先落存储并校验 SHA/etag/version。
  2. 每次获取新增独立 source_batch observation；相同字节也不折叠观测。
  3. partition 获取 lease + fencing token；发布事务锁定 dataset/partition、checkpoint 和 current publication。
  4. 写 canonical batch、typed revision、snapshot/item 和 M:N lineage；身份失败进入 quarantine。
  5. 执行版本化质量规则。blocking 只保存候选/隔离，不推进 durable watermark 或 publication。
  6. 同内容 no-op 复用 dataVersion；变化时创建新不可变 publication 并关闭旧激活区间。
  7. 同事务推进 checkpoint、attempt/run 状态并释放 lease；僵尸 worker 因 token/expiry 校验无法提交。
统一红线：禁止当前名单倒推历史；禁止事后收益/结果进入当时可见记录；禁止后续修订覆盖首次披露；禁止跨来源、口径、币种、单位、粒度或方法学静默混算。
