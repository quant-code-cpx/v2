账户安全与运营查询

在已实施 User/Auth 基线上增加本人 Session family 管理、SUPER_ADMIN 审计读取和角色范围用户统计； 复用 PostgreSQL 权威状态，不保存设备指纹，不新增大而不稳定的 Workspace 聚合接口。

问题

资料与改密已有 API，但会话不可见、审计只写不可读，首页缺少非行情运营数据。

选择

Auth 管本人会话，Audit 管脱敏审计，User 管可管理目标统计；Web 并行组合。

理由

模块所有权清楚，权限最小，不复制状态；未来行情首页上线时仍可复用。

主要风险

审计表增长可能拖慢查询；90 天分批清理和百万行索引门禁控制发布风险。

现状事实与约束

事实

资料与密码写路径已完整

POST /api/v1/users/me、/me/update 和 /me/password 已实现 ETag、当前密码校验、securityVersion、Session 全撤销和事务审计。

事实

Session family 可直接复用

Session 已含 familyId、absoluteExpiresAt、轮换时间与前序关系； 每次受保护请求同时校验 Session 和 User，无需 Redis 权威状态。

事实

审计证据已持续追加

登录、退出、刷新轮换、重放、资料、密码与管理员动作均写入 AuditLog。 当前已实现读取 Controller、稳定 action registry、全局时间索引和独立分批清理任务；在线 保留 90 天且不归档。

固定约束 所有新增 Controller operation 仅用 @Post()；AuthModule 继续只单向依赖 UserModule； PostgreSQL 保存用户、凭证、Session 和审计权威状态，Redis 仅保存短期安全状态；本方案不调用 service-data-sync。

目标、非目标与能力卡

目标

  • 所有角色查看、撤销自己的其他 Session family。
  • SUPER_ADMIN 查询和查看脱敏审计证据。
  • ADMIN/SUPER_ADMIN 获取其可管理目标统计。
  • 为个人中心、安全审计和平台工作台提供冻结契约。

非目标

  • 管理员查看或撤销他人单个会话。
  • 保存 IP、User-Agent、设备指纹或地理位置。
  • MFA、SSO、可信设备、异常登录推断或失败登录审计查询。
  • 行情、同步、搜索、通知、批量用户操作和导入导出。

规划预算

  • 列表 body ≤ 16 KiB；Session ≤ 50 条；审计 ≤ 100 条。
  • 审计默认 7 天、单次最大 90 天。
  • 规划目标：统计 p95 ≤ 300 ms，审计查询 p95 ≤ 500 ms。
  • 延迟仍是验收目标，不作已达事实；实施 PR 必须记录真实容量与 query plan。

核心流程与失败路径

会话撤销

本人 family 强一致撤销

Bearer token
  → Global Guard 解析 sessionId
  → AuthModule 查当前 family
  → 校验目标 family.userId
  → transaction:
      updateMany active family rows
      append sanitized audit
  → 204 / revokedFamilyCount
  → 当前 family：Web 清会话

已撤销终态返回稳定成功；未知或他人 family 返回 404，避免资源枚举。

审计读取

过滤、游标与脱敏映射

SUPER_ADMIN + filters
  → validate 7d default / 90d max
  → bind signed cursor to filter hash
  → indexed AuditLog query + 1 row
  → action registry:
      category / severity / summary
      allowlisted detail fields
  → page + nextCursor + appliedWindow

伪造 cursor、反向时间范围或超 90 天返回 400；数据库失败返回 503。

工作台 partial 失败 API 不提供大聚合端点。Web 仅在获得对应 permission 时并行请求领域查询；Session、统计或审计任一失败， 只让对应区块进入 error/retry。/users/me 的 401 仍由现有 AuthSession 统一清理。

公开契约与错误语义

拟议机器合同： Contract 0017。 已实施资料与改密路径继续以 Contract 0002 为准。

POST path 权限 成功 校验、幂等与失败
/api/v1/auth/sessions/list sessions:read 200，活动 family cursor page pageSize 1–50；cursor 与 actor/filters 绑定；401/403/429/503
/api/v1/auth/sessions/{familyId}/revoke sessions:revoke 204 终态幂等；外部目标 404；当前 family 成功后调用方会话失效
/api/v1/auth/sessions/revoke-others sessions:revoke 200 + revokedFamilyCount 保留当前 family；重复调用返回 0；不改 securityVersion
/api/v1/audit-events/list audit:read 200，脱敏 cursor page 默认 7 天、最大 90 天、最多 100；例行 refresh 默认排除
/api/v1/audit-events/{id} audit:read 200，脱敏详情 不可变无 ETag；不存在 404；无 raw metadata fallback
/api/v1/users/statistics users:read 200，角色范围计数 ADMIN 只含 USER；SUPER_ADMIN 含 USER/ADMIN；actor 与 SUPER_ADMIN 排除

输入与分页

全局 ValidationPipe 拒绝未知字段。时间为带 offset 的 RFC 3339；排序固定 occurredAt desc, id desc 或 createdAt desc, id desc。 opaque cursor HMAC 包含 actor、最后键和筛选指纹。

Problem Details

沿用稳定 application/problem+json。新增问题码只在必要时使用： invalid-time-window、invalid-cursor。不返回 SQL、metadata、token 或 cookie。

缓存

Session 与审计响应使用 Cache-Control: no-store。用户统计可由 Web Query 缓存 60 秒，但 HTTP 层不配置共享缓存。

数据模型、索引与事务

模型 变化 查询与索引 事务/迁移/回滚
Session 无新字段；复用 familyId、createdAt、absoluteExpiresAt、revokedAt 新增 (userId, revokedAt, createdAt, id)，活动 family 分页 撤销与审计同事务；索引可独立删除，无 backfill
AuditLog 保持 append-only String action + Json metadata；响应由 registry 映射 新增 (occurredAt, id)、(action, occurredAt, id) 无数据重写；达到百万行改用受控并发建索引，失败不启用读取路由
User 无字段变化 新增 (role, status, lastLoginAt) 支持范围统计 只读 groupBy/count；索引回滚不改变业务数据
Redis 不新增权威数据；可加读取/撤销限流 key，必须有 TTL key 仅含 actor/family 摘要，不含原始 token 限流状态可丢失；关键 DB 读写不以 Redis 为数据源

migration 只做 expand 索引。audit_logs 少于 100 万行时，由独立 Prisma migration job 在维护窗口创建；达到 100 万行时，发布门禁阻断普通 migration，改用单独评审的 CREATE INDEX CONCURRENTLY 任务。生产应用启动不执行 migration。

AuditLog 在线保留 90 天，首期不归档。部署编排每日触发独立维护任务， 在 PostgreSQL advisory lock 下每批最多删除 5,000 行，直至没有过期数据。任务可重试、 可重复执行，只记录数量、耗时和失败原因；不为清理动作再写审计事件，也不进入 API 应用进程。

结构化日志

记录 requestId、actorId、operationId、result、duration、pageSize、timeWindowDays； familyId、targetId 只记录 HMAC 摘要。不记录响应详情、metadata、密码、token、Cookie。

指标与告警

session families listed/revoked、audit query latency/rows、statistics latency、 audit retention deleted/duration/failure、400/401/403/404/429/503、审计映射 unknown_action。p95 连续 15 分钟超预算或清理连续失败时告警。

健康与恢复

POST /health 不变；POST /ready 继续检查 PostgreSQL/Redis。 读取能力失败不降级为未授权数据；恢复依赖 DB 与索引，不使用缓存副本。
