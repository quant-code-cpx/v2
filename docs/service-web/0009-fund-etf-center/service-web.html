基金与 ETF 中心：PC Web 技术方案

新增基金分类入口、ETF 目录与 ETF 详情三条 PC 路由。产品运行时只调用 service-api； 无真实 publication 就显示无发布状态，禁止内置产品清单、业务数值或图表点兜底。

入口/market/funds
目录/market/etfs
详情/market/etfs/:exchange/:symbol

1. 页面与路由边界

路由 页面职责 真实数据依赖 降级
/market/funds 六类基金能力入口；一期只有 ETF 可进入。 不展示产品数量、收益或规模，因此无需聚合数据。 场外公募、LOF、REITs、货币基金、其他交易所基金标“尚未接入”。
/market/etfs 单交易所 ETF profile 目录、真实筛选、排序和 cursor 分页。 profile v2 publication。 无 publication、来源不可用、筛选空结果三种文案严格区分。
/market/etfs/:exchange/:symbol 身份、状态、日线、NAV/价格比较与 publication 时间。 profile 成功后并发 bar、NAV、state。 每卡独立失败；profile 无法解析 entityRef 时不发后三个请求。
ETF 独立于股票中心。只复用 AppShell、筛选控件、KLineChart/ECharts 容器和远程状态组件； 不复用股票公司资料、资金流 DTO 或代码分类逻辑。

2. 数据适配与远程状态

2.1 EtfMarketDataAdapter

  • 集中定义四个 dataset 的 schemaVersion 2 请求 builder、Zod record 校验和 API Problem Details 映射。
  • exchange 仅接受 URL 中的 SSE|SZSE；小写或其他值均失败关闭；symbol 仅作为代码，不参与基金类别/场所推断。
  • profile 返回稳定 entityRef 后才 enable bar/NAV/state；页面组件不读取原始 envelope 或 provider 字段。
  • 每个 adapter 结果同时携带 records、availability、release、sources、quality、coverage、warnings，UI 不创建综合 dataVersion。
  • CURRENTLY_UNSUPPORTED 是可渲染的成功状态。货币市场 ETF 的 NAV 卡显示 “当前口径暂不支持”，保留产品、价格与状态区域，不把收益型净值解释成单位净值。

2.2 TanStack Query keys

数据 query key 失败边界
目录 ['market-data','etf','profiles',filters] 目录区；完整 filters 包含交易所、关键词、排序、cursor 与固定页大小。
详情身份 ['market-data','etf','profile',exchange,symbol] 详情身份区；成功解析 entityRef 后才启用后三项。
日线 ['market-data','etf','bars',entityRef] KLineChart 卡与收盘价。
NAV ['market-data','etf','navs',entityRef] NAV 卡和比较图 NAV 系列。
状态 ['market-data','etf','states',entityRef] 三维状态条；缺一维只影响该维。

3. 列表、详情与图表

列表

默认 SSE、50 行；开放交易所、代码前缀/名称包含筛选，排序仅 symbol/displayName。官方目录生命周期不可靠，因此当前不开放状态筛选。禁止逐行查行情。

详情

身份和四份 publication 时间优先；管理人/跟踪指数没有真实字段则显示未发布；后续模块完全隐藏。

图表

日线只用 KLineChart；NAV/价格比较只用 ECharts；无 records 时传空数组并展示状态，不生成点。

  • NAV 与收盘价并列原值、双轴、connectNulls=false；日期不一致提示，不补点、不计算折溢价。
  • K 线明确 UNADJUSTED；tooltip 展示 volumeUnit、currency 和各自 publication。
  • 图表懒加载并在路由离开时 dispose；同时提供可键盘访问的最新记录摘要。
  • 不展示规模、跟踪误差、折溢价、换手率、资金流、PCF、事件数值，直到对应真实 dataset 全链路上线。

4. URL、缓存与性能

主题 明确设计
列表 URL ?exchange=SZSE&q=…&sort=displayName&order=desc&cursor=…&page=2；默认值省略；筛选、排序或交易所变化清 cursor；丢弃不可靠的 listingStatus 参数。
详情 URL route params 是唯一分享身份；一期固定读取最近 365 个日历日，不声明尚未实现的 range/panel 状态。
缓存 profile/state staleTime 60 秒，bar/NAV 5 分钟；共享 QueryClient 最多重试一次；无 publication 是成功空响应且不轮询。
负载 列表 50 条；bar/NAV 各最多 366 点；图表引擎不进入 App 初始 bundle。
cursor 不解析 opaque cursor；409 或带 cursor 的 400 validation-error 时清除 cursor 回第一页、保留筛选并提示“目录已更新”。

5. 可访问性、测试与真实数据门禁

  • 桌面最小 1280×720，目标 1440×900；无移动布局、暗色壳层、响应式重排或装饰渐变。
  • 筛选均有可见 label；表格行支持键盘进入详情；状态不只用颜色；图表有结构化摘要。
  • 单元测试覆盖请求 builder、Zod、formatters、availability 文案；组件测试覆盖四查询部分成功、货币 ETF NAV 当前不支持和 cursor 失效。
  • E2E 在空数据库先验证真实无 publication 状态，再运行同步链，从 API 返回的第一条 ETF 导航详情。
  • 测试不得硬编码 ETF symbol、名称、NAV、价格或图点；断言值从捕获的公开 API 响应派生。
  • 生产构建扫描禁止引用市场概览/标的分析的现有测试数据模块、provider URL 或 data-sync 内部地址。
可编辑原型也遵守同一门禁：没有本地真实 publication 时只呈现真实空态和失败态； KLineChart/ECharts 可初始化空数据容器，但不放置任何虚构产品或数值。
