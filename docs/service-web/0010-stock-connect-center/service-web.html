沪深港通中心前端技术方案

在现有 300px sidebar、72px app bar 与 MUI light theme 下新增互联互通总览、通道详情和证券互联互通上下文。 页面只通过 service-api 的五个 POST 端点读取真实 publication 或独立持久化 readiness 证据，不包含样本数据、随机数据或浏览器端估算。

状态：Proposed · 可实施 视口：1440×900 / PC React + MUI + TanStack Query 红涨绿跌 URL 可复现 最后修改：2026-07-30
上线不留卡点：路由、筛选、query key、数据状态、深链接、降级、可访问性和浏览器验收已冻结。路由与导航随 Web 镜像固定部署；在真实 publication 未就绪或 service-api 运行时开关关闭时，页面以明确 fail-closed 状态响应，不依赖 Web 构建期开关，也不存在先上假页面再换数据的阶段。

本次变更摘要：对齐常驻路由、无 publication、部分通道、父版本校验、图表生命周期与 可访问逐点摘要的真实实现边界。

1. 信息架构与页面职责

路由 页面 回答的问题 主接口
/market/stock-connect 互联互通总览 同一共同交易日四条通道表现、状态、额度与官方活跃证券概览。 readiness/query + overview/query + 选中通道 active-securities/query
/market/stock-connect/:channel 通道详情 单通道精确日期统计、日终状态、额度、趋势与官方活跃榜/榜内净额榜。 readiness/query + channels/query + active-securities/query
/market/stock-connect/securities/:instrumentEntityRef 证券互联互通上下文 该稳定证券在互联互通通道内何时、以什么排名和金额出现。 securities/context/query

:channel 仅接受 sh-northbound、sz-northbound、 sh-southbound、sz-southbound。非法值由 route loader 进入站内 404，不发送 API。

1.1 总览页面

  1. 标题区：产品边界、共同交易日、publication 时间、来源和 quality；其下独立显示 candidateTradeDate、readyTradeDate 与逐通道 readiness 证据。
  2. 方向切换：全部 / 北向 / 南向；只改变 URL 和视图，不混合金额。
  3. 四通道卡片：成交额、净买入/净卖出（仅可用时）、额度状态、交易状态、币种。
  4. 趋势区：按币种分组的通道序列；不显示跨币种总线。
  5. 官方活跃证券区：明确“来源活跃证券 Top 10”，通道切换与榜内排序。

1.2 通道详情页面

  1. 面包屑、通道语义、精确日期选择、状态与 publication；readiness 提示独立解释该日休市、等待、失败或来源缺失。
  2. 关键事实：买入、卖出、成交额、净买入/净卖出、额度；每项同时显示 availability。
  3. 趋势图：成交额与可用净额，不把成交额线命名为资金流。
  4. 榜单 tabs：活跃证券 / 榜内净买入 / 榜内净卖出；制度未披露时禁用并解释。
  5. 来源与口径抽屉：数据源、来源 publication 可用性、来源发布时间、接收时间、币种、公式、质量和 dataVersion。来源未提供 publication 时明确显示“来源未提供 publication；接收于…”，不能拿 sourceObservedAt 冒充发布时间。

1.3 证券上下文页面

只展示互联互通范围事实，不承担完整股票/港股详情。北向稳定身份可链接现有 A 股详情；南向若未来存在港股详情， 通过统一 route registry 生成链接。本期无港股详情时仍保留本页，不指向不存在的路由。

2. URL 是筛选状态的唯一可分享来源

参数 取值 默认/规范化
date latest 或 YYYY-MM-DD 默认 latest；API 返回 resolvedTradeDate，但 URL 保持 latest 语义。
direction all|northbound|southbound 总览默认 all；详情由 channel 决定并忽略该参数。
channel 四个 channel slug 总览活跃榜默认 sh-northbound；详情由 path 提供。
ranking active|net-buy|net-sell 默认 active；不可用时保留请求值并展示不可用状态，不静默改 tab。
trendDays 20|60|120|250 默认 20；非法值改写为默认并 replace history。
pageSize 20|50|100 默认 20。
cursor 不透明字符串 筛选或 dataVersion 变化时删除；上一/下一游标保存在 history state。

解析使用集中式 Zod schema；规范化一次后以 replace 写回。所有筛选控件由 URL 派生，刷新、复制链接和浏览器前进后退均可复现。

3. Remote state 与请求编排

stockConnectKeys = {
  overview: (filters, actorRef) =>
    ['stock-connect', 'overview', actorRef, filters],
  readiness: (filters, actorRef) =>
    ['stock-connect', 'readiness', actorRef, filters],
  channel: (filters, actorRef) =>
    ['stock-connect', 'channel', actorRef, filters],
  active: (filters, actorRef, collectionVersion) =>
    ['stock-connect', 'active', actorRef, collectionVersion, filters],
  security: (filters, actorRef) =>
    ['stock-connect', 'security', actorRef, filters],
}
  • 请求统一走现有共享 transport，POST body 与 OpenAPI 一致；组件不直接使用 fetch。
  • 总览成功后，只有当前可见榜单才加载 active query；不预取四通道全部榜单。
  • active POST 必填 parentPublicationDataVersion：总览页传共同 overview 版本，通道页传 channel bundle 版本。409 PARENT_PUBLICATION_MISMATCH 时按“父查询 → active”顺序最多自动 整体复核一次；持续冲突显示版本更新态，人工重试也成对刷新。
  • staleTime=5min、gcTime=30min；publication 是日终不可变版本，窗口聚焦时以 If-None-Match 复核。readiness 使用独立 query key 和 1 分钟 staleTime，正文 dataVersion 按规范 JSON 重算 SHA-256，不能借用父 publication 或其错误状态。
  • 筛选变化取消旧请求；响应只有 query key 与当前 URL 一致时才渲染，避免竞态闪回。
  • 503 时保留 TanStack Query 上一成功数据并显示“连接异常，当前为 dataVersion …”；不得伪装成最新。
  • 新模块不安装 Mock Service Worker、不注册 fixture transport、不把 prototype.html 数据带入 TypeScript。

4. 字段渲染规则

事实 可用 不可用 颜色/符号
成交额 格式化原币金额并显示 CNY/HKD。 “— 来源缺失”。 中性色；不得使用资金流红绿。
净买入 + 金额 · 净买入 “— 未披露（制度）”或“— 来源缺失”。 中国市场语义：正数红色，必须同时有 + 与文字。
净卖出 − 金额 · 净卖出 同上。 负数绿色，必须同时有 − 与文字。
额度 “额度充足”或原始 CNY 余额；显示“日终”。 “— 日终额度来源缺失”。 不把 threshold-above 的空余额显示为 0。
状态 交易日/已收盘/暂停/未开市；买卖接受状态。 “状态未知”，publication 仍可追踪。 不使用仅颜色表达。

数字由共享 formatter 处理，但 money amount 始终先作为 decimal string；不转 JavaScript float 做业务计算。图表输入保留 currency 分组， tooltip 展示完整日期、通道、字段名、符号、文字和币种。

5. 身份、深链接与降级

身份状态 列表呈现 交互
RESOLVED + A 股详情存在 证券名、代码、市场。 主链接到现有股票详情；次入口到互联互通上下文。
RESOLVED + 港股详情尚不存在 证券名、代码、HKEX。 只链接互联互通上下文；不伪造港股详情 URL。
SOURCE_UNRESOLVED 源代码、源名称（若有）、“来源身份未解析”。 整行非链接；提供“查看来源与日期”，不拼 entityRef。
缺少完整港股主数据并不阻塞本模块：只有 HKEX Securities Master 明确给出稳定 Securities ID 且日期化代码生命周期可验证时，才为互联互通事实建立最小稳定身份。 仅有 trading code/name 的行保持 SOURCE_UNRESOLVED。完整港股详情是未来依赖， 不在本期自动扩展。

6. 空、错与复杂状态

状态 页面行为 禁止行为
首次加载 标题/筛选可用，卡片和表格显示固定尺寸 skeleton，aria-busy=true。 不显示上次其他通道值。
精确日无 publication readiness 按持久化证据解释官方闭市、等待交付/执行、失败、来源缺失或尚未齐套； 保留日期选择和返回 latest。 不静默跳到前一交易日。
沪深与香港休市差异 各通道状态卡分别说明；总览 latest 仍取共同已发布日。 不把单边休市写成系统故障。
制度未披露 字段级“— 未披露（制度）”，净额 tab disabled 且有可聚焦说明。 不从成交额反推净买入。
来源缺失/无 publication 业务查询保持 409/503 fail-closed，独立 readiness 提示仍可展示 candidate/ready 日期和逐通道 reasonCode；readiness 也为 READINESS_NOT_OBSERVED 时明确说明“尚无可核验证据”。 公开合同未提供的 requestId 不在浏览器中虚构。 不渲染 0，不加载本地样本。
部分通道失败 若无完整 bundle：总览首次读取明确 fail-closed，不拼装且不承诺存在旧数据。只有 API 成功响应显式提供结构化通道可用性时才逐通道表达；同 query key 后台复核失败时可继续标注并保留已验证缓存。 不把不同日期、版本合成“今日总览”。
父 publication 更新 榜单与父统计整体复核；持续冲突显示“数据版本正在更新”，允许人工成对重试。 不保留旧统计后只读取当前 latest 榜单。
翻页空结果 回到第一页按钮，保留筛选；表头仍显示范围。 不显示“全市场无数据”。
身份缺失 显示源代码/名称与来源身份警告。 不生成不可用链接。

复杂状态视觉稿见 prototype-states.png。

8. 可访问性与视觉验收

  • 所有筛选有可见 label；channel card 可键盘聚焦，Enter/Space 导航；焦点环不被 overflow 截断。
  • tabs 使用 MUI Tabs 语义；不可用 tab 通过邻接说明和 aria-describedby 解释原因。
  • 红/绿之外始终有正负号和“净买入/净卖出”文字；状态 badge 同时有图标或文字。
  • 表格表头 scope 正确，排序按钮有当前方向；loading/error 更新使用礼貌 live region。
  • 趋势图提供包含交易日、成交额、净额和 dataVersion 的逐点可读摘要表；ECharts 关闭动画以满足 reduced-motion，tooltip 不作为唯一信息源。
  • 不使用渐变、玻璃效果、暗色壳层、AI dashboard 装饰、移动端汉堡菜单。

9. 发布、回滚与验收

  1. 合入 API types、transport、导航与路由；页面始终以 fail-closed 状态工作，组件测试只验证状态逻辑，不成为产品数据来源。
  2. 接入真实 staging publication，在受控环境完成 overview、channel、security 页面联调。
  3. Playwright 禁止 route.fulfill 和 service worker mock；记录真实 API 响应 dataVersion 与 DOM 对账。
  4. 三服务验收完成且已有批准 publication 后，运行时开启 service-api STOCK_CONNECT_API_ENABLED；观察 409/503、渲染异常、Web Vitals 与 API p95。
  5. 回滚只关闭 service-api 运行时开关并停用同步计划；Web 保留可分享 URL 和明确不可用状态，不需要重建静态镜像，也不影响现有市场页和数据 publication。
✓ 1440×900 与 1280×800 PC 视口无横向溢出、遮挡、截断；sidebar/appbar 与仓库现状一致。
✓ URL 刷新、复制、前进后退完整恢复日期、方向、通道、榜单、趋势和分页。
✓ 真实 CNY/HKD 不混合求和；成交额文案中不出现“净流入”。
✓ 正数红色且显示“+ / 净买入”，负数绿色且显示“− / 净卖出”。
✓ 北向制度未披露、休市差异、来源缺失、无 publication、部分失败、身份缺失均有确定状态。
✓ readiness 与业务 publication 独立加载和失败；候选日、共同已发布日、证据时间、 状态/reasonCode 均来自 API，浏览器重算摘要与响应 X-Data-Version 一致且不使用当前时间推测。
✓ 浏览器网络只访问 service-api POST 路由，不出现第三方源、data-sync 内部路由或模拟数据路径。

10. 可编辑原型

prototype.html 是 1440×900 PC 可编辑原型入口；它只表达布局、字段可用性和真实 API 装载位置， 不包含虚构证券、日期或金额。评审图： 总览、 通道详情、 复杂状态。
